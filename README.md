# 📅 Calendar Application

![Calendar](calendar.png)

Полнофункциональное приложение календаря на Java Swing.

## ✨ Особенности

• 📆 Отображение текущего месяца  
• ⬅️ Переключение между месяцами  
• 📅 Отображение дней недели  
• 🟢 Подсветка текущей даты  

## 🚀 Быстрый запуск

1. Скачать проект
2. Открыть в IntelliJ IDEA
3. Запустить файл CalendarApp.java
4. Использовать приложение
